Tips

  • Press Space and wait — which-key shows all bindings from that prefix.
  • No tmux — nvim tabs = repo workspaces, splits = tiled panes (Alt = i3).
  • Format on save is enabled via conform.nvim (shfmt, LSP formatters).
  • Spc f p opens or focuses a repo tab. Find/grep stay in that repo.
  • System clipboard is synced — yank in nvim, paste anywhere.
  • Diffview right side is a live buffer — LSP, save, edit all work normally.
  • Persistent undo — history survives across sessions.
  • Oil: rename files by editing their names in the buffer and saving.
